# Результаты проверки прототипа

## Обновление 0.2.0, 7 ноября 2026

Пройдены **38 Lua-тестов и 8 Python-тестов**, а также полный путь синтетических данных CSV → два TSV → два Layout XML. Проверены режим scene (preview/create), сохранение геометрии пикселей при перемещении, явные оси/карты ID, десятичная запятая, ошибки таблиц, неполный XML-экспорт и тайм-аут. Новый расчёт матрицы сравнен с независимой последовательностью поворотов/отражений на 200 случайных примерах; прежние 500 проверок расстояний сохранены.

Оптимизации: четыре тригонометрических вызова на целевой прибор вместо повторения для каждого пикселя; повторное использование разобранного экспортного XML в мастере и проверке результата. Экспорт ждёт распознаваемый полный XML до пяти секунд вместо чтения при первом появлении файла.

Windows-установщик **не запускался**. Настоящие grandMA2 3.9.63.10 и Capture 2024, пользовательский проект и совпадение ID **не проверены**. Синтетические front/top-файлы не являются Layout сцены пользователя. GitHub Actions здесь не учитывается как выполненная проверка.

## Исходный прототип 0.1.0

Дата: 6 ноября 2026. Среда: Linux, Lua **5.3.6**, собранный из исходников Lua; Python 3.12. Внешних библиотек для проекта не требуется.

Выполнена команда `LUA=/tmp/lua-5.3.6/src/lua python3 tools/check.py`:

```text
30/30 tests passed; Lua Lua 5.3. Real MA2/onPC not exercised.
Release checks passed: Lua 5.3, bundle, MA2 descriptor, offline XML/SVG and overwrite refusal.
```

Синтетический пример с двумя шаблонами сформировал десять запланированных назначений пикселей. Для линейки исходный угол `+30°`, конечный `−30°`; при центре цели `(20,10)` крайние пиксели получили `(19.133975,10.500000)` и `(20.866025,9.500000)`. Второй шаблон проверяет матрицу 2×2 с поворотом 45° и отражением.

Файл [example-preview.svg](example-preview.svg) создан из того же результата. Артефакты примера воспроизводятся командами README.

Физическая консоль, grandMA2 onPC 3.9, её собственный plugin_1.lua, реальный экспорт Layout из этой версии, XSD станции, штатные диалоги и GitHub Actions в этой локальной проверке **не запускались**. Настоящие объекты шоу не изменялись. Результат является тестируемым прототипом до прохождения [ручной приёмки](TESTING_RU.md).
